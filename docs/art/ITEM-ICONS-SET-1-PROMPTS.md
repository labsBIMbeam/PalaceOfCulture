## The icon look (locked)

Single centered object at a slight three-quarter top-down game-icon angle on a calm
matte-black-to-charcoal studio backdrop with a soft ground shadow. Warm Bitcoin-orange key
light from the upper left, subtle ultraviolet rim light from the right, restrained
screenprint grain, premium and optimistic. Crisp silhouette, clean depth, calm edges, room
to crop to a circle. **Never:** text, letters, numbers, logos, watermark, frame, interface,
card layout, people, characters, background scenes, floating rings, wireframe polygons,
crypto glyphs, collage or sticker edges, grimdark lighting.

Shorthand used below: `[LOCK]` = "Single centered object, slight three-quarter top-down
game-icon angle, calm matte-black-to-charcoal studio backdrop, soft ground shadow, warm
Bitcoin-orange key light upper left, subtle ultraviolet rim light, restrained screenprint
grain, crisp silhouette, calm edges. No text, letters, numbers, logos, watermark, frame,
interface, people, characters, background scene, floating rings, wireframe polygons, crypto
glyphs, collage, sticker edge or grimdark lighting." Expand `[LOCK]` verbatim when
generating.

## Upload standard (Blossom)

Icons are content-addressed assets — they live on **our Blossom server**, not in git:

1. Export each icon as **1024×1024 WebP** (lossless PNG kept as the working master).
2. Upload to `https://blossom.bimcvp.com` (Blossom BUD-01/BUD-02: blob addressed by its
   sha256, upload authorized with a nostr-signed event — same server the TCG character
   references use).
3. Record every upload in `docs/art/item-icons-set-1.manifest.json`:

```json
{
  "set": 1,
  "icons": {
    "block_stone": {
      "sha256": "<64-hex>",
      "url": "https://blossom.bimcvp.com/<sha256>.webp",
      "mime": "image/webp",
      "bytes": 12345
    }
  }
}
```

The manifest is the source of truth; the HUD swaps its CSS swatches for these icons in a
follow-up branch (see `docs/design/item-sets.md`).
