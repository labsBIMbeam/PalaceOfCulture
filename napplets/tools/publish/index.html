2 · Upload the bytes (Blossom)

The manifest only names a hash — a runtime still has to fetch the file. Blossom is content-addressed, so once the blob is on a server any runtime can resolve it by that hash.

Mirror uses BUD-04: each server pulls the blob from the first one itself, so nothing is re-uploaded. Redundancy matters — if the only host holding your blob goes down, the napplet stops resolving everywhere.

The server list is how a shell discovers which Blossom host holds your blobs — the manifest carries a hash, never a location. Without it a runtime may have the hash and still not know where to look.

5 · Delete old manifests (NIP-09)

A deletion is a request, not a guarantee: relays are free to ignore it, and copies already fetched stay fetched. It also cannot be undone — so list only what you are certain about.
